# Modern DirectX 12 Render Engine Architecture

Dokumen ini adalah architecture blueprint dinamis: diperbarui ketika ada pembaruan

## Basic Principles

Layer paling bawah tidak boleh tahu tentang layer atas. Setiap layer mempunyai satu alasan untuk berubah (Single Responsibility pada level, bukan pada level setiap class kecil). Arah dependency selalu satu arah: App, Scene, Renderer, RHI, Platform

```
==========================================================================
*  Layer 5
==========================================================================
*  App / Tools Layer
*  (Win32 entry point)
==========================================================================
==========================================================================
*  Layer 4
==========================================================================
*  Scene Layer
*  (SceneGraph)
==========================================================================
==========================================================================
*  Layer 3
==========================================================================
*  Renderer Layer
*  (RenderGraph + RenderPass)
==========================================================================
==========================================================================
*  Layer 2
==========================================================================
*  Render Hardware Interface Layer
*  (GraphicsDevice)
==========================================================================
==========================================================================
*  Layer 1
==========================================================================
*  Platform Layer
*  (Win32Window)
==========================================================================
```
